隐私说明

本网站是静态 GitHub Pages 站点，源码没有加入分析脚本、广告追踪器、账号系统、Cookie 或联系表单。GitHub 托管和外部资源提供方仍可能处理正常的网络请求数据。

生效与更新日期：2026 年 8 月 28 日 · 维护者：刘朝

网站代码收集什么数据？

本网站的公开源码没有设置项目自有分析、广告、账户登录、评论系统、邮件订阅或联系表单，也没有通过 Cookie、localStorage 或 sessionStorage 保存访客资料。页面动画使用浏览器本地的 WebGL、计时和可见性接口。

访问页面时会发生哪些网络请求？

服务用途可能处理的数据
GitHub Pages提供 HTML、CSS、JavaScript、robots.txt、sitemap 和 llms.txt正常托管请求可能包含 IP 地址、浏览器信息、时间和请求路径
GitHub / GitHub Raw / Avatars加载公开头像和项目图片，打开代码与项目页面资源请求和跳转访问由 GitHub 的政策管理
X / Bilibili / Shadertoy访问公开身份或背景作品来源点击后由对应第三方处理访问

GitHub 对托管请求的处理适用其 GitHub 隐私声明。

访客可以做什么？

  • 可以在浏览器中禁用 JavaScript；正文、链接和主要资料仍直接存在于 HTML 中，动态背景会停止。
  • 可以阻止第三方图片请求；文字内容与网站内部页面仍可阅读。
  • 可以在打开 GitHub、X、Bilibili 或其他外部链接前查看目标地址及其隐私政策。

隐私问题如何反馈？

请通过联系页面列出的公开渠道反馈网站隐私问题。公开反馈中不要附带密码、访问令牌、私人账号数据或能够识别他人的敏感信息。
