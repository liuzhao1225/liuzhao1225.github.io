What should never be posted publicly?

Do not post passwords, access tokens, API keys, real authentication files, private account data, unpublished project information, or sensitive information about another person in Issues, Discussions, comments, or screenshots. A useful bug report usually needs only the software version, operating system version, visible failure stage, and sanitized reproduction steps.
