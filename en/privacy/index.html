Privacy

This is a static GitHub Pages website whose source adds no analytics script, advertising tracker, account system, cookie, or contact form. GitHub hosting and external resource providers may still process normal network request data.

Effective and updated August 28, 2026 · Maintained by Zhao Liu

What does the website code collect?

The public source adds no first-party analytics, advertising, account login, comment system, email subscription, or contact form. It does not store visitor information through cookies, localStorage, or sessionStorage. Page animation uses local browser WebGL, timing, and visibility APIs.

What network requests occur?

ServicePurposeData it may process
GitHub PagesServes HTML, CSS, JavaScript, robots.txt, sitemap, and llms.txtNormal hosting requests may include IP address, browser information, time, and requested path
GitHub / GitHub Raw / AvatarsLoads public avatar and project images and opens source pagesResource requests and visits follow GitHub's policies
X / Bilibili / ShadertoyOpens public identity pages or the background sourceThe destination handles data after a visitor follows the link

GitHub's handling of hosting requests is governed by the GitHub Privacy Statement.

What choices do visitors have?

  • JavaScript can be disabled; the main text and links remain in static HTML while the animated background stops.
  • Third-party image requests can be blocked; text content and internal pages remain readable.
  • Visitors can inspect each destination and its privacy policy before opening GitHub, X, Bilibili, or another external link.

How can a privacy issue be reported?

Use the public channels on the contact page. Do not attach passwords, access tokens, private account data, or sensitive information about another person to a public report.
