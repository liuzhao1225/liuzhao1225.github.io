什么问题发到哪里？

事项推荐入口原因
具体错误对应仓库的 GitHub Issues便于记录版本、复现步骤和修复状态
功能想法对应仓库的 Discussions 或 Issues让公开讨论与项目上下文保持在一起
开源合作GitHub 个人资料及相关仓库可以直接查看代码、许可证和贡献说明

  • Codex Account Switcher IssuesMac 安装、账号添加、用量与切换问题。
  • Codex Account Switcher Discussions工作流问题、产品建议和工具对比。
  • Claudex Issues安装、模型接入和本地运行问题。
  • Remember Me Issues投稿流程、页面生成和项目建议。

公开反馈时不要发送什么？

请勿在 Issues、Discussions、评论或截图中公开密码、访问令牌、API 密钥、真实认证文件、私人账号数据、未公开项目资料或能够识别他人的敏感信息。错误报告通常只需要软件版本、系统版本、可见错误阶段和经过脱敏的复现步骤。
